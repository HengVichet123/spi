# SPI 非言語

iPhone study app (PWA) for SPI 非言語: browse topics, read worked examples with solutions, tick 「わかる」 per pattern.

Live: https://hengvichet123.github.io/spi/ (Safari > Share > Add to Home Screen)

- `content.js`: topics, methods, hand-written examples. `gens.js`: generators for unlimited examples.
- `app.js` / `app.css`: the app. Ticks are saved on the device (localStorage).
- `sw.js`: offline cache. Bump `VERSION` after changing any file.
